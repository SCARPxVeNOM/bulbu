# Kingdom assets

`scripts/build-kingdom.mjs` assembles `public/kingdom.glb` from these. Only the pieces it uses are kept here.

| Asset | Author | Licence |
|---|---|---|
| `kenney/` — [Fantasy Town Kit 2.0](https://kenney.nl/assets/fantasy-town-kit) | [Kenney](https://www.kenney.nl) | CC0 1.0 (`kenney/License.txt`) |
| `arena/` — Low Poly Arena | [De Alpe Game Art](https://de-alpe-game-art.itch.io/) | Free for commercial use. Its 3×4 pixel palette texture must not be filtered (the build sets NEAREST). |

The island, the Dim (fog), the treasure orb, the observatory dome and the vault coins are made in code (`src/bulbu/kingdom.js`).
