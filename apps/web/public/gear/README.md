# Gear: real-life things Bulbu can hold

One GLB per item, loaded by the 3D engine (`setGear` in `src/bulbu/engine.js`), which measures each model,
scales it to Bulbu's hand, puts Bulbu's own wallpaper on the screen and tints the body in the colour of the
user's own one. The mobile app copies these into `apps/mobile/public/gear` (`scripts/sync-assets.mjs`).

Both were shrunk with gltf-transform (simplified, screen textures removed).
